# 🛍️ onlineStore API

RESTful API для простого онлайн-маркетплейса, написанного с использованием **NestJS**. Проект демонстрирует реализацию работы с пользователями, товарами, корзиной, отзывами и комментариями.

## 🚀 Возможности

### 🔐 Аутентификация
- JWT-аутентификация
- Защищённые маршруты
- Повторная отправка письма активации
- Сброс пароля

### 👤 Пользователи
- Получение и редактирование профиля
- Изменение email
- Обновление контактных телефонов
- Работа с отзывами: создание, редактирование, удаление, ответ на отзыв
- Получение отзывов по пользователю

### 📦 Товары (Items)
- Добавление, редактирование, удаление товара
- Архивация / разархивация
- Поиск по товарам
- Получение информации о товаре

### 🛒 Корзина
- Добавление / обновление товара в корзине
- Удаление товара из корзины
- Получение текущей корзины пользователя

### 💬 Комментарии
- Добавление, редактирование, удаление комментария
- Ответ от получателя комментария
- Получение комментариев по товару

## 📦 Установка и запуск

### 1. Клонируй репозиторий

```bash
git clone  https://github.com/VictoriaKrachilova/onlineStore.git
cd onlineStore
```

### 2. Установи зависимости

```bash
npm install
```

### 3. Настрой конфиг

### 4. Запусти проект
```bash
npm run dev
```

- NestJS
- TypeScript
- PostgreSQL
- Sequelize
- JWT
- Swagger (OpenAPI)
