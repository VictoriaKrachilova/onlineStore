# 🛍️ Online Store Backend

Проект — backend часть интернет-магазина, реализованная с использованием Node.js и TypeScript. Разработан в виде микросервиса с разделением на модули и чистой архитектурой. В проекте реализована работа с товарами, корзиной и пользователями, включая систему ролей и авторизации.

## 🚀 Стек технологий

- **Node.js** + **TypeScript**
- **Express**
- **PostgreSQL** (через `pg`)
- **Redis** (для сессий)
- **Swagger** (для API-документации)
- **Docker** (локальная сборка)
- **Sequelize** (ORM)

## 📦 Функциональность

- Регистрация / авторизация пользователя
- Хранение токена в `httpOnly` cookie
- Роли: пользователь, админ
- Управление товарами (CRUD)
- Корзина и логика заказов
- Swagger UI (доступна на `/api/docs`)
- Обработка ошибок и логирование
