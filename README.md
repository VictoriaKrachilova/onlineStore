# 🛍️ onlineStore API

RESTful API для простого онлайн-маркетплейсу, написаного з використанням **NestJS**. Проект демонструє реалізацію роботи з користувачами, товарами, кошиком, відгуками та коментарями.

## 🚀 Можливості

### 🔐 Аутентифікація
- JWT-аутентифікація
- Захищені маршрути
- Повторне надсилання листа активації
- Скидання пароля

### 👤 Користувачі
- Отримання та редагування профілю
- Зміна email
- Оновлення контактних телефонів
- Робота з відгуками: створення, редагування, видалення, відповідь на відгук
- Отримання відгуків про користувача

### 📦 Товари (Items)
- Додавання, редагування, видалення товару
- Архівування / розархівування
- Пошук за товарами
- Отримання інформації про товар

### 🛒 Кошик
- Додавання / оновлення товару в кошику
- Видалення товару з кошика
- Отримання поточного кошика користувача

### 💬 Коментарі
- Додавання, редагування, видалення коментаря
- Відповідь від одержувача коментаря
- Отримання коментарів по товару

## 📦 Встановлення та запуск

### 1. Клонуй репозиторій

```bash
git clone  https://github.com/VictoriaKrachilova/onlineStore.git
cd onlineStore
```

### 2. Встанови залежності

```bash
npm install
```

### 3. Налаштуй конфіг

### 4. Запусти проект
```bash
npm run dev
```

## 🛠️ Стек технологій
- Node.js
- NestJS
- TypeScript
- PostgreSQL
- Sequelize
- JWT
- Swagger (OpenAPI)
- Docker
